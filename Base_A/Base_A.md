### Markdown 内嵌基础 HTML5
部分 Markdown 编辑器支持直接书写 HTML，常用示例：
```html
<!-- 文字颜色 -->
<span style="color:red;">红色文字</span>
<!-- 换行 -->
<br>
<!-- 表格 -->
<table>
  <tr>
    <th>表头1</th>
    <th>表头2</th>
  </tr>
  <tr>
    <td>内容1</td>
    <td>内容2</td>
  </tr>
</table>
```
