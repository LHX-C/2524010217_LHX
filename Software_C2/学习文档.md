# Software_C2 2. 给定数据集进行目标检测
使用X‑AnyLabeling完成图像标注，YOLOv8作为检测框架，PyCharm作为代码编辑器，Miniconda管理Python虚拟环境。
## 一、学习过程
### 1.环境搭建过程
#### 1.1Miniconda虚拟环境创建
打开Anaconda Prompt执行命令
```bash
conda create -n yolov8_env python=3.11
```
激活虚拟环境
```bash
conda activate yolov8_env
```
安装YOLOv8相关依赖库
```bash
pip install ultralytics opencv-python numpy pillow
```

#### 1.2 PyCharm配置解释器
1. PyCharm打开项目文件夹
2. `File → Settings → Project → Python Interpreter`
3. 添加解释器，选择`Existing environment`，找到miniconda下`yolov8_env`环境的`python.exe`
4. 确认保存，所有代码运行使用该虚拟环境。

#### 1.3 X‑AnyLabeling标注工具
1. github下载X‑AnyLabeling直接运行exe程序
2. 新建标注项目，导入待标注原图
3. 创建类别标签：`社区人员`、`非社区人员`、`电动车`
4. 使用矩形框对目标进行标注，每张图片保存，输出：原图 + 同名`.json`标签文件（LabelMe格式）

> 关键点：一张图片对应一个json文件；json保存图像宽高、标注框像素坐标、类别名称。
> 注意：X‑AnyLabeling输出json，YOLOv8只支持txt格式标签，必须做格式转换。

#### 1.4 数据集划分 train / val / test
|集合|占比|作用|
|----|----|----|
|train训练集|80%|用来更新模型权重，模型学习目标特征|
|val验证集|10%|训练过程实时评估；观察loss、mAP；触发早停；调超参数|
|test测试集|10%|训练完全结束之后才使用，评估模型真实泛化能力，训练阶段不能参与|
> 重要规则：
1. 图片和标签txt成对复制，图片进train，对应txt必须同步进入train；
2. 三个集合样本不能重复；
3. yaml配置文件只填写train、val路径
YOLO标准数据集目录结构
```
my_yolo_dataset/
├─ images
│   ├─ train
│   ├─ val
│   └─ test
└─ labels
    ├─ train
    ├─ val
    └─ test
```

#### 1.5 数据集yaml配置文件
`custom_data.yaml`
```yaml
path: ./my_yolo_dataset
train: images/train
val: images/val

names:
  0: 社区人员
  1: 非社区人员
  2: 电动车
```

#### 1.6 关键训练超参数
```python
model.train(
    data="custom_data.yaml",
    epochs=100,        #最大训练轮次
    imgsz=640,         #输入网络图像分辨率
    batch=8,           #批次大小，显存不足调为4/2
    device=0,          #0使用GPU；无GPU写 device="cpu"
    workers=2,         #Windows设置2，解决dataloader多线程报错
    patience=15,       #早停：连续15轮验证集指标不提升自动停止，防止过拟合
    augment=True,      #开启数据增强，提升泛化能力
    dropout=0.05,      #抑制过拟合
    cos_lr=True,       #余弦学习率衰减
    lr0=0.01           #初始学习率
)
```


#### 1.7 训练输出文件
训练结果输出目录：`runs/train/community_detect/`
1. `weights/best.pt`：验证集指标最优权重
2. `weights/last.pt`：最后一轮保存权重
3. `results.png`：训练曲线图，核心分析文件

#### 1.8训练曲线分析知识点
打开`results.png`，包含Loss、Precision、Recall、mAP50曲线。
1. Box_loss（定位损失）：预测框位置损失；训练集、验证集loss整体下降并趋于平稳为正常。
2. Cls_loss（分类损失）：类别分类损失，持续下降代表分类效果越来越好。
#### 1.9推理效果展示
使用best.pt，通过对test里的图片进行分析，体现训练成果

## 二、关键知识点
1. X‑AnyLabeling 输出 LabelMe 格式 JSON，存储原始像素坐标、图片宽高、标注类别。**JSON 不能直接用于 YOLOv8 训练**，必须转换为 YOLO txt 标签。
2. 一张图片对应一个标签文件（.txt），文件名必须和图片完全同名。
3. 数据划分为train(80%),val(10%),test(10%)
4. 超参数设置

## 三、常见踩坑总结
1. 路径不要包含中文，图片文件名不要中文，避免读取异常。
2. 类别顺序不一致：转换脚本、yaml配置必须保持类别顺序完全一致，否则检测类别错乱。
3. Windows环境`workers`不要设置过大，建议2或者0，避免Dataloader多线程报错。
4. X‑AnyLabeling输出json不能直接训练，必须转换为txt标签。
