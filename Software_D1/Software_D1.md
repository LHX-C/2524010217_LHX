## 一、学习过程
### 1. 基础概念
1.1 强化学习定义
强化学习（Reinforcement Learning, RL）是基于试错学习的交互式机器学习范式。智能体（Agent）在特定环境（Environment）中通过持续执行动作，根据环境反馈的奖励信号，不断调整行为策略，最终学会最优决策，实现长期累积收益最大化。
核心本质：通过与环境交互，从延迟奖励中学习最优行为，区别于被动学习的监督、无监督学习。
#### 1.2 五大核心基础要素
所有强化学习场景均由五大要素构成，是理解所有算法和训练流程的基础：
1. 智能体（Agent）：执行决策、学习优化的主体，如游戏角色、自动驾驶车辆、机器人。
2. 环境（Environment）：智能体所处的外部场景，会接收智能体动作并反馈新状态、奖励。
3. 状态（State, S）：环境当前的全部信息，是智能体决策的依据。
4. 动作（Action, A）：智能体基于当前状态做出的行为选择，分为离散动作（上下左右、开关）和连续动作（车速、机械臂角度）。
5. 奖励（Reward, R）：环境对智能体动作的即时反馈，是评价动作优劣的唯一标准，可正可负。
#### 1.3 核心衍生概念
- 策略（Policy, π）：状态到动作的映射关系，是智能体的决策逻辑，学习的最终目标就是最优策略。
- 价值（Value）：衡量当前状态/动作未来能获得的累积总奖励，用于判断长期收益优劣。
- 回合（Episode）：智能体从初始状态到终止状态的一次完整交互过程（如游戏一局、机器人完成一次任务）。

### 2. 强化学习算法
#### 2.1 动态规划（DP）
核心思路：属于基础的精确求解算法，需要提前获取完整环境模型（所有状态、动作、转移概率、奖励），通过迭代不断更新状态价值，算出最优策略。
特点：
1. 可以得到精确最优解；
2. 必须已知完整环境，现实大部分场景拿不到环境模型；
3. 状态数量变多后计算量爆炸，只适合小规模环境。
适用场景：迷宫、网格世界、状态空间很小的仿真游戏。

#### 2.2 时序差分 TD(Temporal‑Difference)
核心思路：不需要完整环境模型，依靠环境交互采样，用下一时刻的价值来更新当前状态价值，属于无模型算法。
常见版本：
1. TD‑0：单步更新；
2. Q‑Learning：离线版时序差分；
3. SARSA：在线版时序差分。
特点：
1. 不需要环境先验信息，靠和环境交互学习；
2. 可以每一步就更新，不用等待一局游戏结束；
3. 适合中小型离散状态任务。
适用场景：简单迷宫、小车爬坡、小游戏控制。

#### 2.3 Dyna‑Q
核心思路：结合无模型交互 + 环境模型。先用Q‑Learning和真实环境交互，搭建一个简易虚拟环境模型；之后一边真实环境采样，一边在虚拟模型里面额外模拟训练，加快收敛速度。
特点：
1. 真实交互样本少，依靠模拟环境扩充训练数据；
2. 环境模型存在误差，复杂任务模拟效果会变差。
适用场景：交互成本很高、获取真实样本麻烦的小型任务。

#### 2.4 DQN（深度Q网络）
核心思路：深度神经网络代替Q‑Learning的Q表格，用来拟合状态‑动作价值Q(s,a)。
两大机制：
1. 经验回放：存储历史样本，随机采样打破样本之间的关联；
2. 目标网络：分开主网络和目标网络，缓解训练震荡。
特点：
1. 支持图像等高维状态输入；
2. 仅能够处理离散动作；
适用场景：像素类小游戏、贪吃蛇、Atari游戏。

#### 2.5 DQN 系列改进算法
1. Double‑DQN
解决普通DQN容易高估Q值的问题，动作选择、价值评估分开两个网络，抑制价值高估。
2. Dueling‑DQN
网络拆分为状态价值分支、动作优势分支，先评估环境本身好坏，再判断各个动作的优劣，学习效率更高。
3. Noisy‑DQN
给神经网络添加噪声，实现智能体自动探索环境，代替人工设置ε‑greedy随机探索。
4. PER 优先经验回放
TD误差越大的样本优先级越高，优先训练高价值样本，加快收敛。

#### 2.6 策略梯度算法 Policy‑Gradient
核心思路：不再学习价值函数；直接训练策略网络，输入状态，输出动作或者动作概率。依靠回合内总的奖励，朝着提升累积回报的方向更新网络参数。
代表算法：REINFORCE
特点：
1. 原生支持**连续动作**；
2. 需要整局结束之后才可以更新，训练方差大、容易震荡；
适用场景：简单机械臂、小车连续速度控制。

#### 2.7 Actor‑Critic（演员‑评论家，AC）
核心思路：双网络架构
- Actor演员网络：输出动作策略；
- Critic评论家网络：评估当前状态、动作的价值，实时给出更新方向。
特点：
1. 单步即可更新，不需要等待回合结束；
2. 融合价值算法、策略梯度两者优点；
衍生版本：A2C（同步多线程）、A3C（异步多线程）。
适用场景：各类游戏仿真、机器人基础控制任务。

#### 2.8 TRPO 信赖域策略优化
核心思路：属于策略梯度改进算法；约束新旧策略之间的差距，防止一次参数更新幅度太大，直接毁掉已经训练好的策略。
特点：训练十分稳定，但是计算繁琐、运算速度慢，实际项目很少直接使用。
定位：PPO算法的前身。

#### 2.9 PPO 近端策略优化
核心思路：简化TRPO的约束方式，通过裁剪目标函数限制策略更新范围，兼顾训练稳定性和计算速度。
特点：
1. 上手简单、调参难度低；
2. 离散动作、连续动作任务全都兼容；
3. 工业界最通用、使用率最高的算法。
适用场景：机器人控制、无人机、自动驾驶、游戏AI、推荐系统、资源调度。

#### 2.10 DDPG 深度确定性策略梯度
核心思路：Actor‑Critic框架，专门面向**连续动作空间**；演员网络直接输出确定动作，不是动作概率。搭配经验回放机制训练。
特点：只适合连续动作；训练容易不稳定，对超参数十分敏感。
适用场景：机械臂、小车速度、舵机角度这类连续控制任务。

#### 2.11 SAC 柔性演员‑评论家
核心思路：基于最大熵强化学习，在奖励之外额外加入熵约束，鼓励智能体多探索多种动作。
特点：
1. 探索能力强、鲁棒性优秀；
2. 面对复杂、随机、噪声大的环境表现优于DDPG、PPO；
3. 主打连续动作空间。
适用场景：复杂机器人操控、仿真运动、环境存在大量随机干扰的控制任务

### 3. 奖励函数意义和设计
#### 3.1 奖励函数的核心意义
1. 强化学习唯一的指挥棒
智能体不会预先知道任务目标，只能依靠环境返回的奖励判断动作好坏；奖励函数定义了什么行为是优秀、什么行为需要惩罚，直接决定智能体的学习方向。
2. 引导长期收益最大化
智能体优化目标不是单步即时奖励，而是整条轨迹累计奖励。奖励函数需要引导它放弃短期甜头，选择长期最优策略。
3. 决定模型能否收敛、会不会陷入坏习惯
奖励设置模糊、奖励漏洞、多余的正向激励，都会让智能体学会投机取巧、局部最优，无法完成真实任务。

#### 3.2 奖励函数两种基础类型
1. 密集型奖励
每一次动作之后立刻返回数值，训练收敛速度快，适合新手搭建项目。
例子：小车距离终点越近就给予越高的分数；机械臂靠近物体持续加分
2. 稀疏型奖励
中途没有任何反馈，只有到达终点、完成目标才可以拿到奖励。
优点：最贴合真实任务；缺点：训练难度很大，智能体很难随机摸索到成功轨迹。
例子：迷宫只有走到出口才有 + 1 奖励，其余步骤返回 0

#### 3.3 奖励函数通用设计原则
1. 目标对齐
奖励只鼓励有助于任务目标的行为，不要给无关动作加分。
2. 奖惩分明
正向奖励用来鼓励目标动作，负奖励用来惩罚无效、危险、多余的动作。
3. 数值尺度合适
奖励数值不要差距过大，一般建议取值控制在 [-1,1]、[-10,10]，防止梯度爆炸。
4. 优先长期收益，不要过度看重即时回报
例如赛车不要因为提速就加分，否则智能体会一直撞墙加速。
5. 简洁，奖励条目不宜过多
多条互相冲突的奖励标准，会让智能体 confused，难以学习策略。

### 4. 强化学习和其他有监督、无监督学习的相同和不同之处
#### 4.1 相同点
1. 都属于机器学习，依靠数据迭代更新模型参数，让模型持续优化；
2. 均可以使用神经网络当作模型载体，能够处理图像、数值、文本类数据；
3. 存在损失 / 评价指标，依靠反馈不断缩小误差，优化最终效果；
4. 都需要调参、预处理数据、测试评估、规避过拟合问题。

#### 4.2 区别
1. 监督学习（有标签学习）
数据：现成静态数据集，每一条样本带有人工标签（分类结果、真实数值）
学习方式：被动读取数据集，拟合输入和标签之间的映射关系
反馈：每一条样本自带标准答案，训练时立刻就能计算损失
目标：做到输入给出精准预测
典型任务：图像分类、目标检测、房价回归
2. 无监督学习（无标签学习）
数据：不带任何标签的原始数据
学习方式：自动挖掘数据内在结构、分布、特征
反馈：不存在对错标签，依靠数据本身特征做优化
目标：聚类、降维、特征提取、异常检测
典型任务：图片聚类、PCA 降维
3. 强化学习
数据：没有固定数据集，智能体和环境实时交互，动态生成轨迹样本
学习方式：试错探索，一步步尝试动作，在交互当中学习
反馈：延迟奖励；没有标准答案，只有环境给出的好坏评分
目标：学习最优决策策略，最大化长期累计奖励
典型任务：机器人控制、游戏 AI、动态调度

## 二、关键知识点
1. 强化学习基础核心知识点
强化学习核心本质是试错式交互式学习，智能体通过与环境持续交互，接收延迟奖励反馈，迭代优化行为策略，最终实现长期累积奖励最大化，区别于监督、无监督的被动学习模式。
五大核心要素为所有强化学习任务的必备基础：智能体是决策学习主体，环境是交互载体，状态是决策依据，动作是行为输出，奖励是动作优劣的评价标准。
核心衍生概念：策略是状态到动作的映射（最终学习目标）；价值用于评估状态/动作的长期累积收益；回合是单次完整的环境交互任务流程。
2. 主流强化学习算法知识点
算法整体分为三类：基于价值、基于策略、演员-评论家（AC）算法，所有落地算法均由此衍生。
基于价值算法：不直接学习策略，通过拟合最优价值函数间接推导最优策略，结构简单、训练稳定，仅适配离散动作场景，适合入门和简单决策任务。
基于策略算法：直接拟合最优策略，无需依赖价值函数，支持连续、高维动作场景，收敛速度更快，但训练容易震荡，对超参数更敏感。
AC算法（演员-评论家）：融合前两类算法优势，演员负责输出动作策略，评论家负责评估动作价值，兼顾稳定性与通用性，是工业界落地主流算法。
3. 训练流程与应用场景知识点
通用训练全流程：环境初始化→智能体参数初始化→状态采集→动作执行→获取奖励与新状态→迭代更新策略/价值→回合结束循环→模型收敛评估→场景部署。
核心应用场景：游戏AI决策、机器人运动控制、自动驾驶路径规划、推荐系统个性化推荐、资源调度、工业智能控制等序列决策类任务。
强化学习适配无固定标签、动态交互、序列决策场景，不适用于静态分类、回归等传统机器学习任务。
4. 奖励函数核心知识点
奖励函数是强化学习的核心指挥棒，直接决定智能体的学习方向和最终效果，是模型能否收敛、能否得到最优策略的关键。
奖励分类：密集奖励（每步交互均有反馈，训练收敛快）、稀疏奖励（仅任务终点有反馈，训练难度高，需优化设计）。
设计核心原则：目标明确、奖惩分明、数值合理、贴合任务目标；避免奖励冗余、奖励延迟过高、局部最优奖励等问题。
设计核心逻辑：鼓励有效动作、惩罚无效/错误动作、引导智能体长期最优决策，而非单次即时收益最大化。
5. 三类机器学习范式异同知识点
监督学习：基于带标签静态数据集学习，被动拟合数据规律，用于分类、回归任务，无环境交互，无延迟奖励。
无监督学习：基于无标签数据集挖掘数据隐藏特征与分布规律，用于聚类、降维，无交互、无反馈，侧重数据分析。
强化学习：基于环境动态交互学习，无固定数据集，依靠奖励反馈迭代优化，用于序列决策任务，核心是试错与长期收益最大化。
三者核心共性：均为数据驱动的机器学习方法，均通过迭代优化降低误差、提升模型效果。
